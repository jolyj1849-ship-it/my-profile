# Security Policy

## Supported Content
This is a personal learning repository. The small Python tools here are educational samples, not production software.

## Reporting a Vulnerability (in this repo's code)
If you find a security issue in code in this repository:

1. **Please do not open a public issue with exploit details.**
2. Open a private report via GitHub: **Security tab → "Report a vulnerability"** (GitHub private vulnerability reporting), or open an issue titled `Security: please contact me` with no sensitive details and I will follow up.
3. Include: affected file, description, and steps to reproduce in a lab.

I will acknowledge reports as quickly as I can, fix confirmed issues, and credit reporters (unless you prefer to stay anonymous). Thank you for practicing responsible disclosure — I am learning and appreciate the help.

## Scope Reminder
Nothing in this repository authorizes testing against any third-party system. All examples are for an isolated home lab / CTF environments that grant permission.
