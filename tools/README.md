# Tools

Small defensive utilities I wrote to learn Python + security concepts. Pure Python standard library — no installs needed. Each folder has its own README with usage and limitations.

| Tool | Concept it teaches |
|---|---|
| [file-integrity-checker](file-integrity-checker/) | Hashing (SHA-256), tamper/change detection |
| [log-analyzer](log-analyzer/) | Log parsing, brute-force login detection |
| [password-strength-checker](password-strength-checker/) | Entropy, why length beats complexity tricks |

All tools are for education and use on your own systems/files only.
